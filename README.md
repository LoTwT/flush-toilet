# FLUSH

固定俯视的三维抽水马桶。点击冲水按钮、点击水箱上的圆形按钮，或按空格，体验一次完整的冲刷、排水、自动补水和恢复平静。

支持柔和、标准、强劲三档冲水力度；水箱洁厕块可选无添加（清水）、蓝色、薄荷绿、淡紫色，默认蓝色。颜色随水箱出水进入便池，冲刷水柱、旋流与积水保持一致的色调。

马桶盖默认向后掀开，可通过顶部按钮盖上或掀开。

可向便池放入一份排泄物，观察它随水位浮动、被旋流带向排水口，最终下沉并冲走。冲走后可以再次放入，合盖或正在冲刷时暂停放入。

排泄物具有不同的弯曲轮廓、粗细、表面褶皱和湿润光泽。初次放入默认三段，“数量”页提供少（1 段）、中（3 段）、多（6 段）预设；切换数量保留剩余段落的形状与摆放。编辑区通过“+”添加一段、“−”删除选中段，支持 0–12 段；下拉框选择需要编辑的段落，删空后可继续添加。放入后可用鼠标或触摸逐段拖动，在“摆放”页调整旋转与大小；“形状”页提供长条、弯曲、团块预设，并可连续调整弯曲方向、程度和粗细。各段独立编辑，马赛克同步更新轮廓；点击“完成摆放”返回冲水设置，也可以直接冲水。

排泄物默认开启马赛克，用边缘渐隐的柔和模糊遮住细节；可随时通过“马赛克”开关切换，包括正在冲水时。

冲水按钮上方可开启 Boost：冲刷结束即可再次冲水，无需等待补水完成。默认关闭，连续冲水会衔接当前水位。

## 开发

使用 `.node-version` 指定的 Node.js 和 `package.json` 指定的 pnpm 版本。

```sh
pnpm install
pnpm dev
```

```sh
pnpm check
```

`check` 依次执行类型检查、Oxlint、Oxfmt 格式检查、Vitest 和生产构建。`pnpm build` 输出静态文件到 `dist/`，可用 `pnpm preview` 预览。

## 技术

- TypeScript、Vite、Three.js / WebGL 2。
- 参数化陶瓷曲面和可开合椭圆盖、GPU 波纹与泡沫平流、基于水深的吸收与折射。
- 同一条时间轴协调水箱储水、便池水位和分阶段实录水声音效。
- 声音默认关闭，首次进入时询问；可选择“下次不再提示”，在本地记住声音开关。
- pnpm、Oxlint、Oxfmt、Vitest。

浏览器需要启用 JavaScript、WebGL 2，并支持半浮点颜色附件；缺少必要渲染能力时会显示错误并禁用冲水。动画以视觉模拟为目标，完整循环压缩为 12 秒；声音由 Web Audio 播放实录素材。模型与纹理在本地生成，音频随应用提供，运行时不请求外部素材。录音作者、许可与处理记录见[声音素材](public/audio/CREDITS.md)。

开发约定、行为和验证方式见[文档索引](docs/index.md)。
