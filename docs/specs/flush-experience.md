# 冲水体验

## 已确定范围

浏览器中的固定俯视三维马桶，偏写实的白色陶瓷与清透水面。使用原生 TypeScript、Three.js 和普通 CSS；工程化使用 pnpm、Oxlint、Oxfmt、Vitest。

用户点击主按钮、水箱顶部的圆形按钮或按空格，启动一个完整循环。流动依次表现为内沿冲刷、旋转汇聚、虹吸排水、自动回补和余波消退。静止时便池保留水封。

桌面使用有限宽度的三列构图，左列保留文案，中列放置马桶与其下方的冲水操作，右列的水流设置与马桶区域垂直居中，并与左侧文案形成平衡。左右列等宽，让模型和主按钮共同对齐页面中线；模型与主操作适度放大，超宽屏不再将内容向两侧拉散。较窄的桌面窗口将洁厕块选项排成两列，避免挤压文字。相机按界面留出的场景区域适配大小和位置，为下方控件保留间隔。窄屏继续按标题、马桶、设置和冲水操作纵向排列。

水箱与便池分别维护水位；水箱在冲水尚未结束时已经开始补水。默认需要等待整个循环完成才能再次冲水，主按钮显示进行中的状态，水箱进度指示蓄水量。

冲水按钮上方提供 Boost 开关，默认关闭，不跨页面保存。开启后，冲刷与排水结束、进入补水阶段即可再次冲水，无需等待水箱蓄满；冲刷过程中仍忽略重复请求。主按钮显示“再次冲水”，页面按钮、空格和水箱按钮遵循同一规则。提前启动会继承水箱与便池当前水位，水流和声音进入新一轮；不点击则继续补水直至蓄满。补水时关闭 Boost 会立即恢复等待，开启则立即允许再次冲水。

## 座圈与马桶盖

座圈采用宽而略拱的环形坐面，具有独立底壳和支撑垫，与下方陶瓷边沿留有间隙。俯视可见外侧露出的陶瓷、底壳暗边和坐面内侧厚度，避免把座圈看成便池本身的边沿。

椭圆马桶盖包含厚度、内侧凹面、缓冲垫和独立铰链，默认向后掀开 112°，让正上方也能看见盖面。页面顶部可以盖上或掀开盖子，开合采用缓动；盖上时遮住便池，冲水和声音仍可继续。水箱位置为掀盖留出空间，其圆形冲水按钮保持可见。

## 排泄物

默认便池为空。设置区提供“放入排泄物”按钮，初次放入一份由三段不同轮廓组成的排泄物。模型在本地程序化生成，具有弯曲中轴、渐细端部、不规则粗细、棕色层次、细微表面纹理和柔和的湿润光泽；落入便池后贴合当前水位轻微浮动。一份未冲走前，主按钮用于进入或结束编辑。合盖时不能放入，掀盖后立即恢复操作。已有排泄物不影响盖子开合，合盖也可以正常冲走。

编辑区默认打开“数量”页，提供少（1 段）、中（3 段）、多（6 段）预设，一次调整到对应数量。增加时补入新段，减少时从末尾删除；保留其余段落的形状、摆放与浮动进度，当前选中项被移除时选中最后一段。相同数量的预设重复点击不重置场景。预设选中状态始终反映当前数量，手动调整到其他数量时均不选中；删到 0 段后仍可点击预设重新添加。编辑区也可通过“+”添加一段、“−”删除选中段，支持 0–12 段。新增段自动选中，优先放在较空的位置并单独落水，不重置已有段的形状、摆放和浮动进度；沿用当前马赛克开关。删除后选中相邻段，剩余段按顺序重新编号，原有设置不变。达到上限时禁用增加，删到 0 段时显示空状态并禁用删除，仍可通过“+”继续添加。删空后结束编辑，再点击主按钮会重新放入一段。冲水后再次放入沿用本页的数量与各段设置；刷新恢复初始三段。正在冲刷、合盖、声音询问或加载失败时不可增减。

放入后自动进入编辑模式。屏宽大于 1100 像素时，力度和洁厕块保持原位，编辑控件从原排泄物操作区向下展开，以短暂淡入和轻微下移呈现，不把整组设置向上顶；完成后回到原操作行。宽屏短窗口将力度和洁厕块并排，为下方编辑区留出空间。其余宽度暂时用编辑区替换力度和洁厕块。可在场景内用鼠标或单指选择并拖动任意一段，也可通过随数量更新的下拉框选择；半透明的单层绿色细轮廓标记当前段落，线宽不随物件大小或屏幕缩小，中央留空，开启马赛克后仍清晰显示。“摆放”页提供旋转（−180° 至 180°）和大小（原尺寸的 65% 至 130%）调整。进入“摆放”页时自动将焦点交给画布；退出编辑后重新进入仍停留在该页时也恢复画布焦点。画布获得焦点时，方向键或 WASD 可微调位置（W 上、A 左、S 下、D 右），按住 Shift 可将步幅加大为三倍；界面只保留方向键提示。输入控件获得焦点、按住 Ctrl / Command / Alt 或输入法正在组合输入时不触发移动，下拉框仍保留自身的键盘操作。拖动不跳到指针中心，指针移出物件仍继续拖动，抬起、取消或切到后台时停止。位置根据当前水位的便池截面约束，物件不能拖出便池。

编辑区顶部显示数量与操作提示，下方依次为段落选择、成组的减号和加号、“数量 / 摆放 / 形状”切换及参数；底部左侧保留模糊开关，右侧为带勾选图标的“完成摆放”描边按钮，视觉高度 32 像素，窄屏点击区域扩展到 44 像素高。手机将摆放参数分为两列、形状参数分为三列，编辑区与普通设置使用相同高度；进入、退出、切换页面或删空时，场景可用区域不变，马桶不缩小、不移动。放入、调整、完成分别使用加号、编辑和勾选图标，冲水仍是页面的主要操作。

“形状”页可逐段选择长条、弯曲、团块预设，再调整弯曲（−100% 至 100%，正负代表相反方向）和粗细（65% 至 145%）。预设恢复该形态的初始弯曲和粗细，不重置摆放方向与大小；团块的弯曲幅度较小以保持紧凑轮廓。修改会实际重建选中段的三维轮廓、更新命中范围与马赛克，其他段不受影响；变大时必要的位置调整仅用于保持在便池内。形状与摆放设置一同保留到本页的下一份，刷新后恢复默认。

点击“完成摆放”或按 Escape 返回冲水设置，之后可用“调整摆放”再次进入。马赛克开关不会中断摆放，选中轮廓不进入水下折射影像。合盖、接受冲水请求或关闭 Boost 后不再允许操作时，立即结束摆放并释放拖动。冲水直接从自定位置、方向和大小衔接，冲走后再次放入沿用本页的摆放设置；刷新页面恢复默认。摆放是视觉编辑，不模拟物件之间的碰撞或堆叠物理。

“模糊马赛克”开关默认开启，不跨页面保存。开启时以柔和模糊的影像替代原模型，边缘自然渐隐，没有像素方块、矩形底色或硬边阴影；从落入便池、漂浮到冲走均保持细节遮挡，关闭后显示原模型。允许在任意冲水阶段切换，不重置物件位置或冲水进度。模糊影像随物件下沉，并参与水下折射和盖子遮挡；便池为空或排泄物已经冲走时不显示遮挡。

接受冲水请求后，排泄物按当前力度旋转、向排水口汇聚，随排水下沉并缩小，在冲刷结束时清空。它使用同一冲水时间轴，长帧跨过排水阶段也会正常清空；切后台与水流一起暂停。物件属于视觉模拟，不反向改变水量、制造堵塞或染脏池水。

仅在允许再次冲水、马桶盖掀开且便池没有排泄物时可以放入。默认等待完整循环结束；开启 Boost 后，补水阶段即可重新放入，新的一份会停留到下一次冲水，并从当时的水位开始运动。首次声音询问与加载失败时不能放入。

## 力度与水箱洁厕块

冲水力度可选柔和、标准、强劲，默认标准。力度影响座圈下沿七处进水形成的薄层贴壁水流、便池旋流、波纹、泡沫、水箱耗水量以及冲水声量。各档都执行完整循环并恢复原始水位；本次开始后力度锁定，到可以再次冲水时解锁，新的选择在下一次冲水生效。

界面使用“水箱洁厕块”，指放在水箱中持续溶解的固体洁厕剂。可选无添加（清水）、蓝色、薄荷绿、淡紫色，默认蓝色。颜色随水箱出水带入便池，水柱从座圈下沿出现时就有明显染色，与旋转流带和积水保持一致的色调；薄层边缘较透明，泡沫保持较浅。允许在静止或冲水时切换，颜色平滑过渡；每次补水后仍保留所选颜色。保留池底折射与深浅变化，以增加水位和旋流的可见性。配色是视觉设置，不对应实际产品配方或清洁效果。

## 动画与声音

周期与水位的权威值见 `src/constants.ts`，各阶段曲线见 `src/simulation/flush-cycle.ts`。为了方便反复体验，周期采用压缩后的交互时长，不对应具体型号的实际耗时。

主体水面使用二维高度场，局部进水产生波纹，波纹传播并衰减。保留可见的旋转条纹：贴壁水、入水过渡与高度场入口共用流束形状和时钟，水柱的粗细、摆动和颜色连续进入水面，再随速度场拉伸，向排水口汇聚，在回补阶段衰减；泡沫也随同一速度场移动。贴壁水柱沿弯曲路径下落并延伸至水线下方，由主体水面遮挡结束，避免提前淡出留下白环；两者同步加宽，边缘保持柔和。水位与湿润边界仍由共享便池截面决定，排水口位于便池底部之下。

水面和贴壁水层使用同一套透光吸收计算，颜色来自透过水层的池底与陶瓷明暗，不直接在表面混入纯色。主体水深来自背景深度，贴壁水厚度随各股流量变化；进水薄膜的光程和折射跨过水线后逐渐交给池水计算，避免因交界处水深为零而把水柱截断。波纹法线影响折射与高光。入水后的旋转流带保留所选水色，通过光程变化表现深浅。水线处不绘制固定描边，池水高光和泡沫随水深淡出，避免形成整圈亮边；浅白色只用于少量、低覆盖率的气泡。高度场和流动迹线由 GPU 更新，速度场由冲水阶段驱动，属于视觉模拟，不是完整的三维流体求解。

主体画布保留多重采样，并按屏幕尺寸进行适度超采样。水下背景按画布实际像素绘制并独立抗锯齿；水流细节根据像素覆盖范围衰减，减少轮廓台阶和运动中细碎高光的闪烁。

光源靠近顶部，配合环境补光，使投影短而淡，主要落在马桶底座附近。陶瓷与座圈保留柔和光泽，水面只保留低强度高光，避免长条灯面倒影遮盖旋流。旋转细带通过与水色的对比和较连续的流动段落增强可见度，而不是依赖强反光。

背景和模型程序化生成。声音采用随应用提供的冲水与补水实录，按时间轴分别播放。水箱顶部的陶瓷盖固定合上，与可开合的椭圆马桶盖是两个独立部件；补水应表现为隔着水箱盖传出的低闷、轻柔水声，明显弱于便池内的冲刷声。素材通过低通和高频衰减体现遮挡，保留低中频流水起伏，播放时使用较低的补水增益，避免高频嘶声和尖锐阀声突出。

补水从水箱开始回补时接入，使用小水箱的连续实录片段，保留水流起伏、腔体音色变化和关阀收尾；不拼接、不循环、不变速，仅在接入和收尾做短淡化，不用长淡出覆盖关阀过程。补水的音量与音色独立于冲水档位和椭圆马桶盖的开合，不添加正弦波低鸣或电子按钮声。录音来源和编辑参数见[声音素材](../../public/audio/CREDITS.md)。

首次进入默认静音，通过弹窗选择“保持静音”或“开启声音”，默认焦点在保持静音。弹窗期间不能触发冲水；按 Escape 保持静音且不保存选择。勾选“下次不再提示”后，将本次声音开关保存到 `localStorage`，以后跳过弹窗并恢复选择；未勾选则下次进入仍会询问。右上角可随时切换声音，已记忆的选择也会随之更新；存储不可用时不影响本次操作。声音仅在用户操作后解锁播放，记住开启也不会在进入页面时自动播放。静音、后台暂停后重新播放时从当前动画进度接入，不从头重播。

切后台时暂停时间轴、停止绘制并静音，返回后接着播放。减少动态效果偏好会关闭界面的装饰过渡，用户主动触发的核心水流动画保留。

这是一项视觉模拟，不进行工程级三维流体计算。验证命令和浏览器验收范围见[开发与验证](../development.md)。
