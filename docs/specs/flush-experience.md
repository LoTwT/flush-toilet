# 冲水体验

## 已确定范围

浏览器中的固定俯视三维马桶，偏写实的白色陶瓷与清透水面。使用原生 TypeScript、Three.js 和普通 CSS；工程化使用 pnpm、Oxlint、Oxfmt、Vitest。

用户点击主按钮、水箱顶部的圆形按钮或按空格，启动一个完整循环。流动依次表现为内沿冲刷、旋转汇聚、虹吸排水、自动回补和余波消退。静止时便池保留水封。

水箱与便池分别维护水位；水箱在冲水尚未结束时已经开始补水。默认需要等待整个循环完成才能再次冲水，主按钮显示进行中的状态，水箱进度指示蓄水量。

冲水按钮上方提供 Boost 开关，默认关闭，不跨页面保存。开启后，冲刷与排水结束、进入补水阶段即可再次冲水，无需等待水箱蓄满；冲刷过程中仍忽略重复请求。主按钮显示“再次冲水”，页面按钮、空格和水箱按钮遵循同一规则。提前启动会继承水箱与便池当前水位，水流和声音进入新一轮；不点击则继续补水直至蓄满。补水时关闭 Boost 会立即恢复等待，开启则立即允许再次冲水。

## 座圈与马桶盖

座圈采用宽而略拱的环形坐面，具有独立底壳和支撑垫，与下方陶瓷边沿留有间隙。俯视可见外侧露出的陶瓷、底壳暗边和坐面内侧厚度，避免把座圈看成便池本身的边沿。

椭圆马桶盖包含厚度、内侧凹面、缓冲垫和独立铰链，默认向后掀开 112°，让正上方也能看见盖面。页面顶部可以盖上或掀开盖子，开合采用缓动；盖上时遮住便池，冲水和声音仍可继续。水箱位置为掀盖留出空间，其圆形冲水按钮保持可见。

## 力度与水箱洁厕块

冲水力度可选柔和、标准、强劲，默认标准。力度影响座圈下沿七处进水形成的薄层贴壁水流、便池旋流、波纹、泡沫、水箱耗水量以及冲水声量。各档都执行完整循环并恢复原始水位；本次开始后力度锁定，到可以再次冲水时解锁，新的选择在下一次冲水生效。

界面使用“水箱洁厕块”，指放在水箱中持续溶解的固体洁厕剂。可选无添加（清水）、蓝色、薄荷绿、淡紫色，默认蓝色。颜色随水箱出水带入便池，水柱从座圈下沿出现时就有明显染色，与旋转流带和积水保持一致的色调；薄层边缘较透明，泡沫保持较浅。允许在静止或冲水时切换，颜色平滑过渡；每次补水后仍保留所选颜色。保留池底折射与深浅变化，以增加水位和旋流的可见性。配色是视觉设置，不对应实际产品配方或清洁效果。

## 动画与声音

周期与水位的权威值见 `src/constants.ts`，各阶段曲线见 `src/simulation/flush-cycle.ts`。为了方便反复体验，周期采用压缩后的交互时长，不对应具体型号的实际耗时。

主体水面使用二维高度场，局部进水产生波纹，波纹传播并衰减。保留可见的旋转条纹：贴壁水、入水过渡与高度场入口共用流束形状和时钟，水柱的粗细、摆动和颜色连续进入水面，再随速度场拉伸，向排水口汇聚，在回补阶段衰减；泡沫也随同一速度场移动。贴壁水柱沿弯曲路径下落并延伸至水线下方，由主体水面遮挡结束，避免提前淡出留下白环；两者同步加宽，边缘保持柔和。水位与湿润边界仍由共享便池截面决定，排水口位于便池底部之下。

水面和贴壁水层使用同一套透光吸收计算，颜色来自透过水层的池底与陶瓷明暗，不直接在表面混入纯色。主体水深来自背景深度，贴壁水厚度随各股流量变化；进水薄膜的光程和折射跨过水线后逐渐交给池水计算，避免因交界处水深为零而把水柱截断。波纹法线影响折射与高光。入水后的旋转流带保留所选水色，通过光程变化表现深浅。水线处不绘制固定描边，池水高光和泡沫随水深淡出，避免形成整圈亮边；浅白色只用于少量、低覆盖率的气泡。高度场和流动迹线由 GPU 更新，速度场由冲水阶段驱动，属于视觉模拟，不是完整的三维流体求解。

主体画布保留多重采样，并按屏幕尺寸进行适度超采样。水下背景按画布实际像素绘制并独立抗锯齿；水流细节根据像素覆盖范围衰减，减少轮廓台阶和运动中细碎高光的闪烁。

光源靠近顶部，配合环境补光，使投影短而淡，主要落在马桶底座附近。陶瓷与座圈保留柔和光泽，水面只保留低强度高光，避免长条灯面倒影遮盖旋流。旋转细带通过与水色的对比和较连续的流动段落增强可见度，而不是依赖强反光。

背景和模型程序化生成。声音采用随应用提供的冲水与补水实录，按时间轴分别播放并淡入淡出；移除原有的正弦波低鸣和电子按钮声。首次进入默认静音，通过弹窗选择“保持静音”或“开启声音”，默认焦点在保持静音。弹窗期间不能触发冲水；按 Escape 保持静音且不保存选择。勾选“下次不再提示”后，将本次声音开关保存到 `localStorage`，以后跳过弹窗并恢复选择；未勾选则下次进入仍会询问。右上角可随时切换声音，已记忆的选择也会随之更新；存储不可用时不影响本次操作。声音仅在用户操作后解锁播放，记住开启也不会在进入页面时自动播放。静音、后台暂停后重新播放时从当前动画进度接入，不从头重播。录音来源和许可见[声音素材](../../public/audio/CREDITS.md)。

切后台时暂停时间轴、停止绘制并静音，返回后接着播放。减少动态效果偏好会关闭界面的装饰过渡，用户主动触发的核心水流动画保留。

这是一项视觉模拟，不进行工程级三维流体计算。验证命令和浏览器验收范围见[开发与验证](../development.md)。
